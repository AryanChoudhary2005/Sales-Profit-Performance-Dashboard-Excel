## 📌 Project Overview

This project presents an interactive **Sales & Profit Performance Dashboard** created in Microsoft Excel. It transforms raw sales data into meaningful business insights through PivotTables, PivotCharts, KPIs, and interactive slicers.

The dashboard allows users to analyse revenue, profitability, discount impact, customer segments, regions, product categories, and salesperson performance in one place.

## 🎛️ Interactive Filters

The dashboard uses slicers for interactive analysis across:

| Filter | Purpose |
|:--|:--|
| Year | Compare annual performance |
| Month | Analyse monthly sales and profits |
| Region | Compare geographical performance |
| Category | Analyse Furniture, Office Supplies and Technology |
| Segment | Compare customer segments |
| Sales Person | Review individual sales performance |
| Discount Bucket | Understand the impact of discounts on profitability |

---

## 🔍 Key Business Insights

- Sales and profitability can vary significantly across months, regions, and customer segments.
- High discounts can reduce profit margins and may lead to loss-making orders.
- Category, sub-category, and product-level analysis helps identify high-performing and low-performing areas.
- The dashboard enables quick, filter-based decision-making for sales and profitability improvement.

## 🔄 Data Analysis Process

The project was built through a structured Excel analysis workflow:

1. Analysed the raw sales dataset using PivotTables.
2. Created calculations for Sales, Profit, Quantity and Profit Margin.
3. Developed charts to evaluate monthly, regional, product, category, segment and salesperson performance.
4. Analysed the relationship between discount percentage and profit through a scatter plot.
5. Combined the key visuals into an interactive dashboard using slicers.
